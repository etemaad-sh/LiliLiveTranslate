# Lili Live Translate

Android prototype for live Italian ↔ Persian speech translation.

## Features
- Italian speech recognition → Persian translation
- Persian speech recognition → Italian translation
- On-device text translation with Google ML Kit
- Text-to-Speech playback through the phone's active audio output/headset
- One-tap language direction swap

## Cloud build
Every push to main runs the GitHub Actions workflow **Build Android APK** and uploads `LiliLiveTranslate-v1.0.apk` as an artifact.
